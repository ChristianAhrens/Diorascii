Detailed Description

Everything the interactive program does between input and output: the current scene and world, the ASCII menu, style, time of day, pause, info line, toasts and the sound switch.

It performs no I/O of its own (no terminal, no sound device, no clock), so the terminal frontend and other frontends (such as tvOS) drive it the same way: feed it Actions and elapsed time, draw the Frame it renders, and play the sound it asks for.

◆ cycling()

bool dio::Session::cycling ( ) const
inline

True in the overarching cycle mode: the session goes through all scenes by itself, choosing the time of day and the events, and the user's own choices for these are replaced (choosing one by hand, such as the time of day or an event, ends the mode).

Each scene stays until it has shown one full day and night, a rare event (waited for, however many days it takes) and an action (the F key, triggered at random every 10 to 90 seconds). Otherwise (the user mode) all of that is manual.
