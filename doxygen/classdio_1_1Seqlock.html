Detailed Description

template<typename T>
class dio::Seqlock< T >

The latest value of a plain-data type, written by one thread and read by one other without locks, allocation or waiting (a "seqlock").

The writer never waits for the reader. The reader gets a complete value, never a mix of two writes: if a write is in progress it retries a few times and then reports failure, so that a real-time thread can carry on with the value it had.

Meant for the parameters the main loop hands to the audio thread: one copy of the whole struct, so adding a field needs no change anywhere else.
