◆ ColorMode

enum class dio::ColorMode
strong

How colors are written.

Cells flagged defaultFg/defaultBg always use the terminal's own colors, whatever the mode. TrueColor - 24-bit Ansi256 - xterm 256-color palette Ansi16 - the 16 named ANSI colors (follow the user's terminal theme) Console - the Linux text console (TERM=linux): 16 colors with only 8 usable backgrounds, which are snapped to the dark ones

Encodes cur as VT/ANSI output.

If prev is non-null and the same size, only changed cells are emitted; otherwise the whole screen is repainted. Pure function (no I/O), so it is unit-testable and shared by all platforms.
