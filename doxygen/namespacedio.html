double t )

Dissolves from into to (the crossfade between two scenes): each cell shows its glyph from to once t passes a fixed per-cell threshold (a scatter, so the picture dissolves rather than wipes), and where both cells have plain colors those are blended too.

Cells with the terminal's own colors or reverse video are taken whole from one side, as they have no color to blend. The result replaces to; nothing is done unless both frames have the same size.

Parameters

◆ negotiate()

Negotiation dio::negotiate ( const LayoutChoice & choice,
const DeviceReport & report )

Chooses the layout.

Automatic: 7.1.4 on a route of one or two channels that spatializes; else the device's own map if it has one, without the unused channels at its end (a named layout if the map is exactly that layout's channels in its order, or, for an exact map, in any order, in which case the layout is routed), else the richest of 9.1.6, 7.1.4, 7.1, 5.1 and 2.0 that fits the count; a single channel is a single speaker. A named choice is rendered as asked, even above what the device has (downmixed); on a device with an exact map it is routed to the device's channels of the same positions (routed) instead of reopening the device with the layout's map, and if the device has no place for one of its channels the richest layout below it that the device has is routed instead (layout then names that one: 7.1.4 asked on a 5.1 device gives 5.1), except on a device of one or two channels, which is opened with the layout's map as for any device without an exact map and left to the system to mix down.
