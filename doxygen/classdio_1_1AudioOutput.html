Detailed Description

Opens the default playback device and feeds it from an Ambience.

Platform differences are handled by miniaudio. The device runs on its own thread; setParams() is safe to call from the main loop at any time (one writer thread): the parameters reach the audio thread as one consistent copy through a Seqlock, so a new field of AmbientParams needs no change here.

The synth renders to the device's speaker layout (see negotiate()): by default the richest one the device reports, or the one that was asked for, stepping down to a smaller one if the device does not open with it.
