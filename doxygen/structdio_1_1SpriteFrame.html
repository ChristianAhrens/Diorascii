Detailed Description

One animation frame.

mask has the same shape as art: art ' ' + mask ' ' -> transparent art ' ' + mask '_' -> opaque (hides what is behind, keeps background) art ' ' + mask color char -> solid block of that color art glyph + mask char -> glyph drawn in the mask's color Mask chars: digits 1-9 pick the entity's randomized palette, letters are fixed colors (see world.cpp), ' ' means the entity's default color.
