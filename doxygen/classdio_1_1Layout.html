Layout dio::Layout::fromDevice ( const DeviceChannel * channels,
int count )
static

Builds a layout from what a device reports.

Each channel keeps the position given and is identified with the nearest canonical channel; LFE channels stay LFE, channels without a known position are silent. Only the first kMaxChannels entries are used; the backend writes silence to the rest.

Finds the two speakers that carry a stereo signal: the L and R channels if the layout has them, else the leftmost and rightmost directional speakers.

With one directional speaker both indices are that speaker.
