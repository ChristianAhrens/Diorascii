# Diorascii app icon assets

Mountains scene (day and night) with two eagles, drawn like the app itself: solid colour cells with ASCII glyphs on top.
Everything is generated by `make_icons.py` (glyphs become vector outlines, so the SVGs need no font).

    pip install fonttools          # optional for PNG export: rsvg-convert on PATH
    python3 make_icons.py          # rewrites everything below
    tvOS/make_rasters.sh           # then: 2x layer images and the Top Shelf images (needs ImageMagick);
    tvOS/make_rasters.sh tvOS/night   # run it again for the night variant (it also writes the catalog Contents.json)

## Layout

| Path | Purpose |
|---|---|
| `tvOS/layers/{back,middle,front}.svg` | 1280x768 layer sources. Back = sky + sun + clouds (opaque), Middle = mountains, forest, meadow, Front = eagles |
| `tvOS/App Icon & Top Shelf Image.brandassets/` | Xcode asset-catalog image stacks (Large 1280x768, Small 400x240), PNG rendered from the layers |
| `tvOS/preview/` | composite preview |
| `tvOS/night/` | same structure for the night variant (moon, stars, tinted mountains) - swap in for a night icon |
| `square/layers/*.svg` | 1024x1024 layers: sky, sun, mountains, eagles |
| `square/layers/*-night.svg`, `square/preview/icon-night-1024.png` | night variant of the square icon |
| `square/Diorascii.icon/` | Icon Composer bundle (sky = background fill, Sun / Mountains / Eagles = layers); day and night art are separate layers (Sun/Moon, Mountains/MountainsNight, Eagles/EaglesNight, Sky/SkyNight); day layers are hidden in the Dark appearance and night layers only show there (`hidden-specializations`), the background fill has a dark variant too |
| `square/preview/` | composite preview |

## Design notes

* tvOS: keep the single focal point (the two eagles) inside the 370x222 safe zone of the 400x240 tile. The Front layer
  moves most under parallax, so only the eagles live there.
* Square: condensed variant of the tile (32x32 cells, steeper peaks, one cloud, shorter meadow) so the eagles stay legible.
* The eagle sprites (`EAGLE_UP`, `EAGLE_GLIDE` in the script) are a candidate refresh of `assets/forest/eagle.sprite`:
  doubled `\\ //` feather tips, a tail row, white `v` head.
* Glyph outlines come from DejaVu Sans Mono (free licence). Swap `--font/--bold` to use another monospace font.

* Night: moon is the app's `moon_big` shape, stars are `*` / `.` glyphs, rock/snow/forest/meadow are tinted blue. Eagles are `active: day` in the app; in the icon they are drawn pale (moonlit) so they stay readable on the dark sky.

## Not verified yet

* The `.brandassets` structure and `Diorascii.icon/icon.json` were written from the documented/known formats and
  from the existing Mema/Umsci bundles. They have not been opened in Xcode / Icon Composer. Open once and adjust
  (in particular the background gradient and layer shadows).
* The dark-appearance wiring (`hidden-specializations`, night layers with fill `none` in Dark) follows community documentation of the `.icon` format, not an Icon Composer export - check in Icon Composer that Dark shows the night scene (moon, stars, tinted mountains). `image-name-specializations` is deliberately not used: it is ignored by `ictool`.
* The Top Shelf images are a draft: a crop of the composite tile (Resources/Icon/tvOS/make_rasters.sh), not a
  dedicated design. App Store Connect requires them (Info.plist key `TVTopShelfImage`, produced by the catalog).
