Detailed Description

The simulation: owns entities, advances them in fixed-size steps and renders the result into a Frame.

No I/O and no clocks - fully deterministic per seed.

Member Enumeration Documentation

◆ TimeMode

enum class dio::World::TimeMode
strong

How the time of day advances.

Dawn, Day, Dusk and Night freeze it at a fixed moment; Realtime leaves it to the frontend, which sets it from the host's clock (see setPhase()), because the core has no clock of its own.
